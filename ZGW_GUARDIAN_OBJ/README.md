# ZGW_GUARDIAN_OBJ

## Description
This project is for creating an OData V2 service that exposes Guardian Objects and their Quick Info.

## Structure
- **Entity Types**:
  - GuardianObject
  - GuardianQuickInfo

- **Associations**:
  - Object_QuickInfo

- **Entity Sets**:
  - GuardianObjects
  - GuardianQuickInfos

## Implementation Steps
1. Create SEGW project.
2. Define entity types and associations.
3. Generate runtime classes.
4. Implement necessary methods.
5. Provide annotations for Fiori UI.
6. Register the service.
7. Create Fiori UI components.
8. Implement authorization and filtering.
9. Validate and optimize performance.
